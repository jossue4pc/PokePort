# PokePort v0.1.5 — actualizador corregido / updater fix

**Español**

- **Corregido:** la actualización desde el lanzador fallaba con «El proceso no puede obtener acceso al archivo
  'icon.ico'…» (el propio lanzador tenía el icono bloqueado). Ahora el lanzador carga el icono en memoria y el
  actualizador solo reemplaza los archivos que cambian, uno a uno; si algo falla, restaura la versión anterior.
- **Nuevo:** el lanzador detecta si el juego se compiló con otra versión (por ejemplo, si copiaste archivos nuevos a
  mano) y te pide **Reinstalar** para aplicarla; mientras tanto puedes seguir jugando con la anterior.
- Incluye todo lo de la v0.1.3 y v0.1.4 (caché de shaders de PokéPark, preparación de shaders al arrancar, modo
  diagnóstico, selector Direct3D 12 / Vulkan, compartir caché de shaders).

**Si tienes la v0.1.2 o anterior,** su lanzador tiene el fallo del icono, así que actualiza **a mano esta vez**:
cierra el lanzador, descarga `PokePort-v0.1.5.zip`, copia el contenido de su carpeta `PokePort-v0.1.5` encima de tu
carpeta actual (reemplazando archivos), abre el lanzador y pulsa **Reinstalar**. Tu partida, ajustes y disco extraído
se conservan. Desde aquí las actualizaciones serán automáticas.

**English**

- **Fixed:** updating from the launcher failed with "cannot access the file 'icon.ico'" (the launcher itself kept the
  icon locked). The launcher now loads the icon from memory and the updater only replaces files that changed, one by
  one; any failure restores the previous version.
- **New:** the launcher detects when the game was built from another version (e.g. files copied by hand) and asks you
  to **Rebuild**; meanwhile the previous build keeps working.
- Includes everything from v0.1.3 and v0.1.4.

**On v0.1.2 or older,** update **by hand this once**: close the launcher, download `PokePort-v0.1.5.zip`, copy the
contents of its `PokePort-v0.1.5` folder over your current folder (replace files), open the launcher and press
**Rebuild**. Saves, settings and the extracted disc are kept. From then on updates are automatic.
