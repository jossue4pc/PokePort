# PokePort v0.1.1 — corrección del instalador / installer fix

**Español**

- **Corregido:** al pulsar *Instalar* con un disco cuyo nombre o ruta tenía apóstrofos (por ejemplo
  `PokePark Wii - Pikachu's Adventure (USA).rvz`) la instalación no arrancaba y el lanzador decía
  «¡Instalación terminada!» sin hacer nada. Ahora la ruta se pasa tal cual, sin importar espacios ni apóstrofos.
- **Corregido:** el lanzador solo anuncia que terminó cuando la instalación termina de verdad; si algo falla muestra
  el paso, el error y el registro (`.build\build_*.log`).

Si probaste la v0.1.0: descarga `PokePort-v0.1.1.zip`, descomprímelo y vuelve a pulsar **Instalar**.
Las instrucciones completas están en el [README](https://github.com/jossue4pc/PokePort#readme).

**English**

- **Fixed:** with a disc image whose name or path contained an apostrophe (e.g.
  `PokePark Wii - Pikachu's Adventure (USA).rvz`) *Install* did nothing and the launcher reported "Installation
  finished!". Paths are now passed verbatim, whatever spaces or apostrophes they contain.
- **Fixed:** the launcher only reports success when the installation really finished; failures show the step, the
  error and the log (`.build\build_*.log`).

If you tried v0.1.0, download `PokePort-v0.1.1.zip`, extract it and press **Install** again.
