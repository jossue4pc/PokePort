# PokePort v0.1.2 — actualizaciones automáticas / automatic updates

**Español**

- **Nuevo: actualizaciones desde el lanzador.** Al abrirlo comprueba si hay una versión nueva y muestra un aviso con
  **Ver notas**, **Actualizar**, **Ahora no** y **Omitir esta versión**; también hay un botón **Buscar actualizaciones**
  y la versión instalada aparece arriba a la derecha.
- La actualización es segura: verifica la descarga (SHA-256), hace copia de seguridad y la restaura si algo falla, no
  toca tus partidas, ajustes, disco extraído ni herramientas, y solo recompila lo que cambió. El `PokePark.exe` anterior
  sigue funcionando hasta que el nuevo compila bien.
- **Reinstalar** ya no vuelve a extraer el disco si es el mismo.
- La carpeta del juego se actualiza de forma atómica (si el juego está abierto, pide cerrarlo y no rompe el exe).
- Corregido: al reinstalar se anidaban carpetas (`fonts\fonts`).

**Importante:** si tienes la v0.1.0 o v0.1.1, descarga esta versión a mano una vez (`PokePort-v0.1.2.zip`). A partir de
aquí el lanzador se actualizará solo.

**English**

- **New: updates from the launcher.** On start it checks for a new release and offers **Release notes**, **Update**,
  **Not now** and **Skip this version**; there is also a **Check for updates** button and the installed version is shown
  at the top right.
- Updating is safe: the download is verified (SHA-256), the current version is backed up and restored if anything
  fails, saves/settings/extracted disc/toolchain are never touched, and only what changed is rebuilt. The previous
  `PokePark.exe` keeps working until the new one builds.
- **Rebuild** no longer extracts the disc again when it is the same image.
- The game folder is updated atomically (if the game is running you are asked to close it; the exe is never broken).
- Fixed: rebuilding nested folders (`fonts\fonts`).

**Important:** if you have v0.1.0 or v0.1.1, download this version manually once (`PokePort-v0.1.2.zip`). From now on
the launcher updates itself.
