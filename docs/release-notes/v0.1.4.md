# PokePort v0.1.4 — sin tirones por shaders / shader stutter work

**Español**

- **Preparación de shaders al arrancar:** la primera vez verás «Preparing shaders (first start only): X / Y» unos
  segundos; después los efectos conocidos ya están compilados.
- **Menos competencia con el juego:** durante la partida los shaders nuevos se compilan con 1 hilo en CPUs de hasta 8
  hilos (portátiles) y 2 en CPUs de hasta 16, en vez de 4. Ajustable con `MKW_SHADER_THREADS`.
- **Compartir caché de shaders** (botón morado del lanzador): crea un ZIP en el escritorio con los efectos que tu PC
  ya preparó. Envíalo para que se añada a la caché del port y nadie tenga tirones en esas zonas la primera vez.
- Los releases se publican automáticamente desde GitHub Actions.

Actualiza desde el lanzador (*Actualizar*).

**English**

- **Shader preparation on first start:** "Preparing shaders (first start only): X / Y" for a few seconds; known effects
  are compiled before you play.
- **Less contention with the game:** new shaders compile with 1 thread on CPUs with up to 8 threads (laptops) and 2 on
  up to 16, instead of 4. Override with `MKW_SHADER_THREADS`.
- **Share shader cache** (purple launcher button): zips the effects your PC prepared, to be added to the port's seed so
  nobody stutters there the first time.
- Releases are now published automatically by GitHub Actions.

Update from the launcher (*Update*).
