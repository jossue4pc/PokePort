# PokePort v0.1.3 — rendimiento y diagnóstico / performance and diagnostics

**Español**

- **Caché de shaders de PokéPark incluida.** Hasta ahora el port traía la de *Mario Kart Wii* (1 101 shaders que
  PokéPark no usa) y se compilaba en segundo plano en cada arranque, compitiendo con el juego: en procesadores de 4
  núcleos causaba tirones los primeros minutos. Ahora trae la de PokéPark (178), que se prepara en las primeras
  pantallas en vez de la primera vez que aparece un efecto (romper una caja, una zona nueva...). Al actualizar se limpia
  una vez la caché antigua (solo shaders; partidas y ajustes no se tocan).
- **Modo diagnóstico** (botón naranja del lanzador): juega unos minutos y al cerrar verás un resumen (CPU/GPU, trabajo
  por fotograma, tirones por causa) y el archivo para enviarlo.
- **Elegir API gráfica:** Auto, Direct3D 12 o Vulkan (en GTX 10xx prueba Vulkan).

Se actualiza desde el lanzador (*Actualizar*); recompila solo lo que cambió.

**English**

- **PokéPark shader seed bundled.** The port used to ship *Mario Kart Wii*'s seed (1101 shaders PokéPark never uses),
  compiled in the background at every start and competing with the game — stutters for the first minutes on 4-core
  CPUs. It now ships PokéPark's own (178), prepared during the first screens instead of the first time an effect
  appears. Updating resets the old shader cache once (saves and settings untouched).
- **Diagnostic mode** (orange launcher button): play a few minutes; on exit you get a summary (CPU/GPU, work per frame,
  stutters by cause) and the file to share.
- **Graphics API choice:** Auto, Direct3D 12 or Vulkan (try Vulkan on GTX 10-series).

Update from the launcher (*Update*); only what changed is rebuilt.
