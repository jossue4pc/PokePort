# System fonts

`font_western.bin` and `font_japanese.bin` are the free replacement IPL fonts made by the Dolphin
emulator project (https://github.com/dolphin-emu/dolphin, `Data/Sys/GC/`), distributed under
Dolphin's license (GPL-2.0-or-later). They are not Nintendo's fonts. The port serves them to the game
as the console's built-in font ROM (`__OSReadROM`).
